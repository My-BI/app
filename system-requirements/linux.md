# System requirements — Linux

*Current as of MyBI 26.1.0, 11 August 2026.*

**Not yet released.** A Linux build exists and is built by our pipeline, but it is not published or supported. There is no download to point you at, and no support commitment behind it.

When it does ship, the shape it is built for is a 64-bit distribution with WebKitGTK 4.1 — Ubuntu 22.04 and later, or equivalent — as an AppImage and a .deb. Treat that as intent, not a promise.

For what MyBI does support today, see [macOS](mac.md) and [Windows](windows.md).
