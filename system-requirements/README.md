# System requirements

What MyBI needs, per platform. One file each, so a page or a support reply can link to exactly the
platform being asked about instead of a wall covering five others.

| Platform | Status |
|---|---|
| [macOS](mac.md) | Released — macOS 12 Monterey or later, Apple Silicon and Intel |
| [Windows](windows.md) | Released — Windows 10 1809 or later, 64-bit |
| [Linux](linux.md) | Not released |
| [Android](android.md) | Not released |
| [iOS](ios.md) | Not released |
| [iPadOS](ipados.md) | Not released |

Each file carries the release it is current as of. When a requirement changes, say what it was
before as well — someone reading it is usually asking whether their own machine still qualifies, and
that question is only answerable if the previous floor is written down.
